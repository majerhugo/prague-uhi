# CrowdQC+ kontrola kvality – plán implementácie

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Po uzavretí UTC dňa označiť stanice Netatmo, ktoré neprešli kontrolou CrowdQC+ (m1–m5), uložiť príznaky do archívu a v mape ich skryť (šedo na požiadanie).

**Architecture:** `qc.py` exportuje 30-dňové okno z archívu do CSV, `qc.R` spustí originálny balík `CrowdQCplus`, `qc.py` príznaky zapíše do `archive/qc/RRRR-MM-DD.json`. `archive.build_web` príznaky pridá do `days/*.json`, `index.html` ich zobrazí. Krok vo workflowe je neblokujúci a R sa inštaluje len vtedy, keď je čo počítať.

**Tech Stack:** Python 3.12 (stdlib + `requests`), R ≥ 3.5 s `CrowdQCplus` (GPL-3; `data.table`, `robustbase`, `lubridate`, `terra`, `geodata`), Leaflet, GitHub Actions (`r-lib/actions/setup-r@v2`).

**Spec:** `docs/superpowers/specs/2026-11-07-crowdqc-design.md`

## Global Constraints

- Použiť **originálny** balík `CrowdQCplus` ≥ 1.1.2, kroky **m1–m5**, `complete = TRUE`, `keep_isolated = TRUE`, voliteľné kroky o1–o4 vypnuté, ostatné parametre predvolené.
- Okno **30 dní** končiace uzatváraným dňom; deň = **UTC deň**, uzavretý je deň pred dnešným UTC dňom; zapísaný deň sa nemení (len `--recompute`).
- Stanice s menej než **24 platnými hodinami** v okne sa do R nedávajú a mapa ich **zobrazuje** (bez príznaku).
- Označené stanice sú v mape **skryté**, prepínač vrstvy ich ukáže **šedo**; do štatistík panelu sa nepočítajú.
- Neuzavretý deň je v mape surový s textom `preliminary, not yet quality-checked`.
- Krok kvality je vo workflowe **neblokujúci** (`continue-on-error: true`); chýbajúci R alebo chyba nikdy nezastaví publikovanie.
- Archív sa len dopĺňa (append-only); `fetch.py` sa lokálne nespúšťa bez `--no-fetch`.
- UI aj texty webu po anglicky; komentáre a výpisy v kóde po slovensky (ako doteraz).
- Pred každým pushom, mergom a mazaním vetvy sa pýtame používateľa; vývoj na vetve `qc`; commit končí `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Menej než ~100 staníc v okne alebo `cqcp_check_input` zlyhá** → `run_day` nezapíše súbor, vráti `False`, deň sa skúsi pri ďalšom behu (Task 2, test `test_too_few_stations_writes_nothing`).
2. **Prázdny archív / žiadny uzavretý deň bez súboru** → `--pending` vypíše `pending=false`, `qc.py` skončí s kódom 0 (Task 3).
3. **Chýbajúce hodinové snímky v okne** (medzera) → príznaky len pre existujúce snímky, nepadá to (Task 2, test `test_gap_in_window_is_ok`).
4. **Stanica sa presunula** (dva riadky registra s rovnakou MAC) → riadky sa hodnotia ako dve samostatné stanice (Task 2, test `test_moved_station_rows_are_separate`).
5. **Rscript nie je dostupný** (lokálne bez R, alebo zlyhal) → `main` vráti 2, nič nezapíše, web sa zostaví bez príznakov (Task 3 test, Task 6 `test_pipeline.sh`).
